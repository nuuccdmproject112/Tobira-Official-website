[完整說明]
設計理念與痛點 = 《巷口的第五頁》以 IP 角色設計為起點，結合苗栗在地商家、NFC 感應技術與互動式故事任務，打造一場串聯虛擬與現實的探店體驗。
    故事從一隻失去記憶的貓咪展開，透過角色的視角，帶領大家走進熟悉又充滿故事的巷弄，在不同的店家中尋找線索、解鎖記憶，一步步拼湊出藏在日常生活裡的故事。
目標使用者與情境 = 主要面向對在地文化與互動體驗有興趣的年輕族群、觀光旅客，以及有意透過創新行銷吸引客群的在地商家。
    使用情境：遊客或消費者在苗栗街區探店時，透過 NFC 票卡感應，連結 ESP32 機台，以 Line 互動接收故事推播，完成沉浸式的探店任務。
核心功能與特色 = IP 角色驅動的探店動線：以失憶貓咪 IP 串聯各個合作商家，每家店都是故事的一個章節。
    NFC 感應互動機制：玩家持 NFC 票卡靠近機台（ESP32 + RC522）觸發事件，與 Line 官方帳號連動接收故事推播。
    虛實整合的敘事體驗：數位故事與實體探店相互融合，讓「逛街」變成「解謎冒險」。
使用技術與工具 = NFC 感應硬體：ESP32 微控制器搭配 RC522 感應模組，讀取 NFC 票卡 UID。
    Line Messaging API：透過 Webhook 與 Line 官方帳號整合，依感應結果推播對應的故事章節。
    IP 角色設計：原創角色視覺設定、故事腳本與探店地圖設計。
目前成果 = 已成功建置 NFC 感應機台，能以 NFC 票卡感應後導入顧客的 Line 並進行故事推播。
