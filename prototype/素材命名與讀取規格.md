# 組別素材整理方式（統一使用中文）

承辦與各組日常整理的資料夾、圖片、文字檔均使用中文。英文 JSON 是工具產生的網站資料，不需要開啟或修改。

範例：content/groups/第01組_留一扇門給日常/

- 作品資料.txt：用記事本開啟，只改中文欄位等號右側內容。
- 第01組_留一扇門給日常_主視覺.jpg
- 第01組_留一扇門給日常_門卡.jpg（選填，沒有時使用主視覺）
- 第01組_留一扇門給日常_海報.jpg（選填，沒有時使用主視覺）
- 第01組_留一扇門給日常_團隊合照.jpg
- 第01組_留一扇門給日常_成果展示_01.jpg ～ _07.jpg
- project.json：自動產生，請勿手動編輯。

圖片也可使用 PNG。組號與成果照片序號補成兩位數。每張不超過 10 MB（目前掃描工具尚未強制檢查大小）。成果照片建議 5～7 張。

新增時複製 templates/組別範本_複製後改名，改資料夾名稱、作品資料.txt 內的組號與文案，換上圖片。圖片辨識只看末端用途，不依賴前綴完全相同；但建議依規格命名方便人工查找。門卡／海報選填，主視覺／團隊合照／至少一張成果照必備。同用途不能放兩張。

雙擊專案根目錄 start-preview.cmd，會掃描組別、辨識用途與照片順序，產生網站所需 JSON。預覽已開啟時可執行 python scan-content.py 後刷新頁面。不要執行 build-prototype.py，這是早期產生示意資料的開發工具。

作品資料.txt 的完整說明可以寫多行，續行前面留四個空白；組員用「、」分隔。圖片說明以 01、02 對應成果照序號。其他連結以「連結名稱 = 完整網址」每行一筆；沒有的項目保留空白。

網站不是直接掃描 Google 雲端硬碟，而是在本機啟動或發布前掃描資料夾。中文檔名可以正常使用，發布時也須保留 UTF-8 與正確網址編碼。
